1. INTRODUCTION
  • Clinical Reagent Strips: Multi-analyte dipsticks (10-SG) provide rapid point-of-care screening for 10 metabolic parameters (Glucose, Protein, pH, Ketones, Blood, Leukocytes, Nitrite, Specific Gravity, Bilirubin, Urobilinogen).
  • Subjectivity Limitations: Manual human inspection against printed color cards suffers from observer bias, fatigue, delayed read times, and inconsistent illumination.
  • Automated Solution: An end-to-end containerized microservices platform integrating Computer Vision, CIE Lab colorimetry, and Machine Learning.
  • DevOps Foundation: Adopts industry-standard DevOps practices: containerization, multi-language testing, and automated Jenkins CI/CD pipelines.
2. PROBLEM STATEMENT
  • Manual Bottlenecks: Evaluating 10 reagent pads simultaneously within strict chemical reaction windows (30s–120s) leads to diagnostic inaccuracies and absent audit records.
  • Architectural Vulnerability: Monolithic medical applications lack fault isolation; a vision or AI module failure crashes the entire clinical dashboard.
  • Scope & Boundaries: Focuses on automated processing of a standardized 10-pad vertical strip layout using controlled calibration references. Academic demonstration prototype; not intended for clinical diagnostic use.
3. OBJECTIVES
  • Computer Vision Pipeline: Detect urine strips, enforce strict image quality filters (Laplacian blur score & brightness thresholds), and extract individual pad bounding boxes.
  • Perceptual Colorimetry: Extract central median pad crops to eliminate border glare; convert RGB to HSV and CIE L*a*b* for Delta-E distance matching.
  • Explainable AI Assist: Train an offline Random Forest classifier on synthetic reference distributions to provide category predictions and confidence scores.
  • Microservice Architecture: Decouple vision, colorimetry, AI, and storage into independent FastAPI containers behind an Express API Gateway.
  • DevOps Automation: Implement multi-container Docker Compose orchestration and an automated 7-stage Jenkins CI/CD pipeline.
4. LITERATURE REVIEW
  • Shen et al. (2012): Demonstrated smartphone-based colorimetric detection for biochemical test strips; proved feasibility but identified lighting sensitivity as the primary bottleneck.
  • Yetisen et al. (2014): Proved that perceptual CIE L*a*b* color spaces significantly outperform raw RGB Euclidean distances for diagnostic colorimetry.
  • Jalal et al. (2017): Established central median crop sampling to filter out border reagent bleeding, reflections, and uneven edge illumination.
  • Newman (2021) - Microservices: Established architectural paradigms for distributed microservices, emphasizing decoupled fault isolation and API gateways.
  • Research Gap: Existing point-of-care software lacks microservices resilience (graceful degradation when AI fails), containerized portability, and automated CI/CD pipelines.

6. IMPLEMENTATION DETAILS
  • Frontend Dashboard: React 18, Vite 5, live pad bounding box overlays, color swatch previews, RGB/HSV/Lab measurement table, and MongoDB history cards.
  • API Gateway: Express orchestrator managing multipart routing, timeout handling, and fallback logic.
  • Image Service (CV): OpenCV Laplacian blur detection (rejects blur score < 80), brightness validation (35–245), and coordinate generator for 10 vertical pads.
  • Colorimetry Service: Central 50% median crop; RGB → HSV → CIE Lab conversion; Delta-E Euclidean comparison against configured reference charts.
  • AI/ML Service: Scikit-Learn Random Forest (100 estimators, 6 features [R,G,B,L*,a*,b*]) loaded offline from joblib model; outputs class probabilities.
  • Result Service & DB: FastAPI motor service storing comprehensive records in MongoDB 7.0 without collecting personal patient information.

8. KEY FINDINGS
  • CIE Lab Superiority: Perceptually uniform CIE Lab Delta-E matching eliminated color classification ambiguity across all 10 demonstration test swatches (Delta-E < 3.3).
  • Median Crop Noise Rejection: 50% central median sampling effectively filtered out pad edge shadows, reflections, and paper background artifacts.
  • High Architectural Availability: Disabling the AI container triggered instantaneous gateway fallback to reference matching with 0% user-facing downtime.
  • Jenkins CI/CD Efficiency: Full multi-language test suite, Docker builds, and health deployment completed in 5 minutes 57 seconds with 100% stage reliability.
9. CONCLUSION
  • End-to-End DevOps Solution: Successfully designed and validated a distributed microservices platform unifying Computer Vision, Colorimetry, and DevOps CI/CD.
  • Loose Coupling & Scalability: Independent Docker containers ensure individual services can be scaled, updated, or restarted without impacting the overall system.
  • Automated Quality Gates: Integrated dual CI/CD pipelines (GitHub Actions + Jenkins) ensuring code quality and regression prevention before deployment.
  • Academic Impact: Serves as a robust demonstration of modern DevOps microservice engineering applied to digital biochemical sensing workflows.
